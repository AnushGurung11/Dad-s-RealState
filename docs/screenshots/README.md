## Capture notes

- Physical Android device, portrait, 1080×2400 or similar; no emulator chrome.
- Use **Load sample data** so no real tenant names, phone numbers, or photos appear.
- Blur or avoid faces in tenant photos.
- Record a 15–25 second screen recording of: open app → switch month → assign tenant →
  record rent payment → open finance table. Save as `docs/screenshots/demo.mp4`, and convert
  to `demo.gif` (≤ 8 MB) for the README.
